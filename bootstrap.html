Conhecendo o Bootstrap

Esta página explica a ferramenta usada para construir o OmniEsports: o que é, para que serve, como funciona o sistema de grid, o conceito de responsividade e quais componentes do framework foram aplicados no projeto.

O que é o Bootstrap?

O Bootstrap é um framework front-end de código aberto, criado originalmente pela equipe do Twitter, que reúne um conjunto de arquivos CSS e JavaScript prontos para construir interfaces web. Em vez de escrever do zero cada botão, menu ou grade de colunas, o desenvolvedor usa classes já definidas pelo framework para montar a página.

Neste projeto ele foi incluído via CDN, direto no <head> de cada página, sem precisar baixar nenhum arquivo:

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
...
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>

Para que serve?

O Bootstrap resolve problemas que apareceriam em qualquer site feito só com CSS próprio: manter um alinhamento consistente entre páginas, adaptar o layout a telas diferentes e evitar reescrever componentes de interface (menus, cartões, botões, tabelas) toda vez que são usados. No OmniEsports, ele garante que a Navbar, os Cards de jogos/notícias e as tabelas de classificação tenham sempre o mesmo comportamento e a mesma base visual em todas as 14 páginas, mudando apenas a cor de destaque de cada jogo.

Sistema de Grid

O grid do Bootstrap organiza o conteúdo em até 12 colunas dentro de uma estrutura de três níveis:

  • .container — cria a área central da página, com margens e largura máxima responsiva.
  • .row — uma linha que agrupa colunas.
  • .col, .col-md-*, .col-lg-* — colunas dentro da linha; o número após o breakpoint indica quantas das 12 colunas o elemento deve ocupar naquele tamanho de tela.

Exemplo real usado nos cards de notícias deste site (arquivo noticias.html):

<div class="container">
  <div class="row g-4">
    <div class="col-12 col-sm-6 col-lg-3">...</div>
    <div class="col-12 col-sm-6 col-lg-3">...</div>
  </div>
</div>

Responsividade

Design responsivo é a prática de construir uma página que se adapta ao tamanho da tela de quem está acessando, seja um celular, um tablet, um notebook ou um monitor grande, sem quebrar o layout nem exigir zoom ou rolagem lateral.

O Bootstrap facilita isso através dos breakpoints: pontos de quebra que definem a largura mínima da tela a partir da qual uma regra passa a valer.

PrefixoLargura mínimaDispositivo típico
(nenhum)0px📱 Celulares
sm576px📱 Celulares grandes
md768px📱 Tablets
lg992px💻 Notebooks
xl1200px🖥️ Monitores maiores

É por isso que a Navbar do OmniEsports vira um menu recolhível (navbar-expand-lg) abaixo de 992px, e por isso os cards de jogos e notícias usam classes como col-12 col-sm-6 col-lg-3: uma coluna cheia no celular, duas no tablet e quatro a partir do notebook.

Componentes utilizados no projeto

Estes são os principais componentes do Bootstrap aplicados nas páginas do OmniEsports:

Navbar

Menu de navegação fixo no topo, presente em todas as páginas, com dropdown de campeonatos e versão recolhível para telas pequenas.

Card

Utilizado para organizar informações em blocos visuais: jogos, notícias, partidas e lançamentos, sempre com a mesma estrutura de imagem, título e texto.

Dropdown

Usado no item "Campeonatos" da Navbar para agrupar os 9 jogos por categoria (FPS, MOBA, Battle Royale, Fighting, Esportes/Corrida).

Badge

Pequenas etiquetas coloridas que identificam o jogo ou o status de uma notícia/lançamento, como "Pré-venda" ou "Beta aberto".

Table

Exibe a classificação de cada campeonato (vitórias e derrotas dos times) de forma organizada e com rolagem horizontal em telas pequenas.

Botões (Button)

Classes como btn btn-primary e btn btn-outline-light usadas para as chamadas de ação, como "Ver campeonatos" e "Buscar".
