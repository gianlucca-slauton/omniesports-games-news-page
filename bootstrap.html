Bootstrap

Um framework de 12 colunas que organiza o caos de construir layouts que funcionam em qualquer tela.

O que é Bootstrap?

O Bootstrap é um framework front-end gratuito e de código aberto, criado originalmente pela equipe do Twitter, utilizado no desenvolvimento de sites e aplicações web. Ele reúne um conjunto de arquivos HTML, CSS e JavaScript já prontos — com classes e componentes reutilizáveis, como botões, menus, formulários e cards — que agilizam a criação de interfaces organizadas e funcionais, sem que seja preciso escrever todo o código de estilo do zero.

Para que serve?

O Bootstrap ajuda a resolver problemas comuns do dia a dia do desenvolvimento web:

  • Agilidade: evita reescrever estilos básicos repetidamente, poupando tempo de desenvolvimento.
  • Padronização visual: garante uma aparência consistente em todas as páginas do site.
  • Responsividade: facilita páginas que se adaptam a diferentes tamanhos de tela.
  • Compatibilidade entre navegadores: reduz diferenças de exibição entre Chrome, Firefox, Edge etc.
  • Facilidade de manutenção: segue um padrão conhecido, fácil de entender e alterar.

Sistema de Grid

O sistema de Grid do Bootstrap é uma malha baseada em 12 colunas, que organiza o conteúdo da página de forma flexível. Ele funciona em três níveis: o container, que envolve e centraliza o conteúdo; a row, que forma uma linha; e a col, que divide essa linha em colunas.

<div class="container">
  <div class="row">
    <div class="col-md-6 col-lg-4">Coluna 1</div>
    <div class="col-md-6 col-lg-4">Coluna 2</div>
    <div class="col-md-12 col-lg-4">Coluna 3</div>
  </div>
</div>

Glossário:

container

Envolve toda a estrutura e centraliza o conteúdo na página.

row

Cria a linha onde as colunas serão distribuídas.

col

Define uma coluna de largura automática, dividindo o espaço igualmente.

col-md

Comportamento em telas médias (tablets) — ex.: col-md-6 ocupa metade da linha.

col-lg

Comportamento em telas grandes (notebooks/monitores) — ex.: col-lg-4 ocupa um terço da linha.

Responsividade

Design responsivo é a prática de criar páginas que se ajustam automaticamente ao tamanho da tela do dispositivo, garantindo boa experiência de visualização em qualquer aparelho. O Bootstrap facilita isso combinando o grid com breakpoints — classes específicas para cada faixa de tamanho de tela.

📱 Celulares col- < 576px
📱 Tablets col-md- ≥ 768px
💻 Notebooks col-lg- ≥ 992px
🖥️ Monitores maiores col-xl- / col-xxl- ≥ 1200px / 1400px

Assim, um mesmo bloco pode ocupar 100% da tela em um celular e apenas um terço em um monitor grande — sem precisar criar páginas diferentes para cada dispositivo:

<div class="col-12 col-md-6 col-lg-4">
  Ocupa 100% em celulares, 50% em tablets e 33% em notebooks/monitores.
</div>

Componentes utilizados no projeto

Pelo menos 5 componentes do Bootstrap foram utilizados no desenvolvimento do site:

Navbar

Barra de navegação fixa usada para exibir o menu principal do site, com links para as seções/páginas.

Card

Utilizado para organizar informações em blocos visuais, como imagens, textos e botões agrupados.

Button

Botões estilizados usados para ações como enviar formulários ou navegar entre páginas.

Carousel

Exibe uma sequência de imagens ou conteúdos em um slide rotativo, ideal para banners e destaques.

Form

Captura dados do usuário, como nome, e-mail e mensagem, com estilização pronta para os campos.

Footer (Grid Layout)

Estrutura baseada no sistema de grid usada para organizar o rodapé, distribuindo contato e redes sociais.
